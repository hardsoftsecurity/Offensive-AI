# Contributing

## Philosophy
This repository focuses on practical offensive AI research.
Contributions should prioritize:
* Real attack value
* Clarity and structure
* Reproducibility

## Guidelines

### Content
* Avoid generic explanations
* Focus on exploitation techniques
* Provide examples and payloads

### Structure
Follow existing folder and file conventions.

### Payloads
* Keep them categorized
* Avoid duplicates
* Include variations when relevant

### Tools
* Keep code clean and minimal
* Include usage instructions
* Focus on practical utility

## Reporting Issues
Use issues for:
* Suggestions
* Improvements
* Corrections

## Disclaimer
Only contribute content that is safe, legal, and intended for ethical security research.
